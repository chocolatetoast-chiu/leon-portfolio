# Why the signal matters

A bigger model doesn’t always mean better quantification — the right path to the signal does.

Path A

MRI-based

Structural MRI + PET: FreeSurfer-grade anatomy, classical SUVR / Centiloid when MRI is available.

Gold-standard anatomy — when MRI is available.
Path B

MRI-less

Synthetic CT training → quantify on PET/CT without paired MRI; validated on external cohorts.

Access when MRI is missing — without giving up defensibility.
